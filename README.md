# سكن — حسابات الشقة المشتركة

موقع لحسابات السكن المشترك: المصاريف والتقسيم، مين ليه ومين عليه، التسويات والدفع المباشر بإنستاباي، الصندوق المشترك، العدادات، التأمين والعهد، المشتريات، المهام بالدور، الإعلانات والتصويت — مع لوحة تحكم كاملة للمدير يشغّل منها أو يقفل كل ميزة وكل صلاحية.

يشتغل على **GitHub Pages** (استضافة مجانية) و**Firebase** (قاعدة بيانات وتسجيل دخول مجاني)، ويتثبّت على الموبايل كتطبيق.

---

## الإعداد — مرة واحدة (حوالي ١٠ دقايق)

### ١) مشروع Firebase
1. ادخل https://console.firebase.google.com واعمل **Add project** (اسم زي `sakan-home`) — Google Analytics مش مطلوب.
2. من القائمة: **Build ← Authentication ← Get started ← Sign-in method ← Google ← Enable ← Save**.
3. **Build ← Firestore Database ← Create database** ← اختار أقرب Location (مثلًا `eur3` أو `me-central1`) ← **Start in production mode**.
4. في Firestore افتح تاب **Rules**، امسح اللي فيه، والصق محتوى ملف `firestore.rules` كله ← **Publish**.
5. من ⚙️ **Project settings ← General ← Your apps ← أيقونة الويب `</>`** ← سمّيه `sakan` ← **Register app**. هيظهرلك `firebaseConfig`.
6. افتح ملف `firebase-config.js` والصق القيم مكان `PASTE…`.

> مفتاح `apiKey` في Firebase مش سر — الحماية الحقيقية في قواعد `firestore.rules`.

### ٢) الرفع على GitHub Pages
1. ادخل https://github.com/new واعمل ريبو جديد (مثلًا `sakan`) — **Public**.
2. في صفحة الريبو: **Add file ← Upload files** واسحب **كل محتوى الفولدر** (كل الملفات) ← **Commit changes**.
3. **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save**.
4. بعد دقيقة أو اتنين الموقع هيبقى على: `https://<اسمك>.github.io/sakan/`

### ٣) اسمح للدومين يسجّل دخول
في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** ← اكتب `<اسمك>.github.io` ← Add.

خلاص — افتح الموقع، ادخل بجوجل، واعمل السكن.

---

## الاستخدام

1. أول واحد يعمل السكن بيبقى **المالك والمدير**.
2. من **الأعضاء** ضيف أسماء السكان (والوزن لو الأوض مختلفة، والتأمين).
3. من **الأعضاء ← كود الدعوة** ابعت اللينك للسكان. كل واحد يدخل بجوجل ويختار اسمه.
4. كل ساكن يحط **لينك إنستاباي** بتاعه من «الأعضاء ← بيانات الدفع بتاعتي».
5. من **الإدارة** شغّل المزايا اللي محتاجها، وظبط الصلاحيات، والفواتير الثابتة، والميزانية، وأسعار العدادات.

### على الموبايل كتطبيق
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة للشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## الأدوار والصلاحيات

| الدور | يقدر |
|---|---|
| **مدير** | كل حاجة: الأعضاء، الأدوار، المزايا، الصلاحيات، قفل الشهور، تعديل وحذف أي بند |
| **عضو** | حسب مفاتيح «صلاحيات الأعضاء» في الإدارة |
| **مشاهد** | يتفرّج بس |

مفاتيح صلاحيات الأعضاء (المدير يشغّلها ويقفلها): تسجيل مصروف باسم غيره · تعديل بنوده · تأكيد الدفعات من المستلم · رؤية أرصدة الكل · المشتريات · الإعلانات · التصويت · قراءات العدادات · اشتراك الصندوق · الانضمام بالكود.

الصلاحيات المهمة متطبّقة على **السيرفر** في `firestore.rules` (مش في الواجهة بس): مثلًا العضو ما يقدرش يسجّل مصروف باسم غيره، ولا يعدّل في شهر مقفول، ولا يأكد دفعة مش ليه، ولا يغيّر دوره.

## المزايا (كلها بتتشغّل وتتقفل من الإدارة)

التسويات · الدفع بإنستاباي والمحافظ · تذكير واتساب · صور الإيصالات · الفواتير الثابتة مع تنبيه الاستحقاق · الميزانية · الصندوق المشترك · العدادات · التأمين والعهد وتسوية الخروج · المشتريات · المهام بالدور · الإعلانات · التصويت · أرقام مهمة وقوانين السكن · الإحصائيات · سجل النشاط · كشف الحساب · ملخص الشهر — بالإضافة لـ: أكتر من سكن لنفس الحساب، وضع غامق/فاتح، شغل من غير نت (بيتزامن لما يرجع)، تصدير CSV ونسخة احتياطية JSON.

## ملاحظات

- صور الإيصالات بتتضغط وتتحفظ في Firestore نفسه (مش محتاج Firebase Storage المدفوع).
- الخطة المجانية لـ Firebase (Spark) كفاية جدًا لسكن واحد أو كذا سكن.
- حذف السكن بيشيل الوصول ليه، لكن البيانات القديمة جوه Firestore بتفضل — تقدر تمسحها من الكونسول لو حبيت.
